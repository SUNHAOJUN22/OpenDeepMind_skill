## danyuchn/first-principles-skill

- Repository: <https://github.com/danyuchn/first-principles-skill>
- License: MIT
- Repository notice: the project identifies itself as a fork of `tt-a1i/first-principles-skill` and adds a “Phase 0 — Delete First” requirement check.

**Influence on OpenDeepMind:** explicit testing of whether a requirement should exist, followed by problem definition, assumption challenge, ground-truth identification, upward reconstruction, and validation.

**Modifications:** OpenDeepMind replaces the six-phase single-engine flow with a dual-engine architecture; adds First Philosophy, typed proposition ledgers, domain routing, causal and scale-bridge audits, a 100-point quality system, scripts, schemas, examples, and original visual assets.

No source text from its example library is reproduced verbatim.

## smixs/creative-director-skill

- Repository: <https://github.com/smixs/creative-director-skill>
- Creator/attribution: Serge Shima
- License: Creative Commons Attribution 4.0 International

**Influence on OpenDeepMind:** phase routing, method-selection discipline, recursive self-evaluation, explicit stopping criteria, structured deliverable templates, and a visual README with explanatory diagrams.

**Modifications:** all domain content has been replaced. OpenDeepMind does not reproduce the campaign database, scoring criteria, creative methods catalog, or examples. It introduces an original philosophy–principles method, new terminology, new rubrics, new templates, new scripts, and newly generated diagrams.
