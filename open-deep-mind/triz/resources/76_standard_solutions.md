# 76 Standard Inventive Solutions / 76 个标准解

This working reference operationalizes classical Su-Field analysis. It follows the five-class organization documented in the source module and reconciled there against Salamatov/Mann training traditions. Treat the entries as solution-model prompts, not experimentally validated designs.

## Class taxonomy

| Class | Name | Diagnostic use | Count |
|---:|---|---|---:|
| 1 | Composition & decomposition of Su-Fields | incomplete system or harmful coupling | 13 |
| 2 | Evolution of Su-Fields | complete but insufficient/uncontrollable action | 23 |
| 3 | Transition to supersystem or micro-level | structural bottleneck/local saturation | 6 |
| 4 | Detection & measurement | information/measurement problem | 17 |
| 5 | Strategies for introducing substances & fields | resource-economical implementation | 17 |

Total: **76**.

## Diagnostic flow

```text
Build current Su-Field model S1 ←F— S2
        |
Missing S2 or F? -------------------- yes → Class 1.1
        |
Harmful action? --------------------- yes → Class 1.2
        |
Insufficient/uncontrollable action? - yes → Class 2
        |
Measurement/information problem? ---- yes → Class 4
        |
Local improvement saturated? -------- yes → Class 3
        |
Use Class 5 to minimize added substances/fields/resources
```

## Notation

- `S1`, `S2`, `S3`: substances/objects;
- `F`, `F1`, `F2`: fields/interactions;
- `S1 --F--> S2`: useful action;
- `S1 --F_harm--> S2`: harmful action;
- `S1'`: modified form;
- `[A] → [B]`: transformation.

# Class 1 — Composition & Decomposition of Su-Fields (13)

## 1.1 Synthesis of Su-Fields

**1.1.1 Simple Su-Field synthesis.** Complete an interaction by adding the missing substance or field.

**1.1.2 Internal complex Su-Field.** Add an internal additive to an existing substance when direct change is constrained.

**1.1.3 External complex Su-Field.** Add a separate intermediate substance outside the original substances.

**1.1.4 Use the environment as the third substance.** Prefer air, fluid, structure, surroundings, or other supersystem resources.

**1.1.5 Modify the environment with an additive.** When the environment is available but lacks the needed property, modify it minimally.

**1.1.6 Maximum mode through an intermediary.** Deliver intense local action through an intermediate element so the primary tool/object is protected.

**1.1.7 Selective maximum action.** Keep average action low while making it maximal only in the operational zone/time.

**1.1.8 Use a phase/state-changing material to enable or signal action.** Exploit threshold-dependent changes such as phase, color, magnetism, geometry, or conductivity.

## 1.2 Destruction of harmful Su-Fields

**1.2.1 Introduce a third substance.** Interpose `S3` to shield, absorb, neutralize, separate, or redirect a harmful action.

**1.2.2 Modify existing substances instead of adding a foreign one.** Derive the protective/intermediate effect from `S1` or `S2` via coating, phase/state change, segmentation, or local modification.

**1.2.3 Drain harmful action through a third substance.** Provide a preferential sink/path for heat, stress, contamination, vibration, electric charge, etc.

**1.2.4 Apply a counter-field.** Introduce `F2` to neutralize or control harmful `F1`.

**1.2.5 Disable a ferromagnetic interaction above the Curie point when applicable.** Use a physical property threshold to eliminate the coupling.

# Class 2 — Evolution of Su-Fields (23)

## 2.1 Transition to complex Su-Fields

**2.1.1 Chain Su-Field.** Introduce an intermediate stage/substance/field to improve controllability or transformation.

**2.1.2 Dual Su-Field.** Add a second independent field acting in parallel with the first.

## 2.2 Dynamization and forcing evolution

**2.2.1 Replace a poorly controllable field with a more controllable one.** Select the field on engineering merits rather than a rigid universal hierarchy.

**2.2.2 Fragment the substance.** Bulk → segmented → granular → powder → liquid/gas/dispersion where useful.

**2.2.3 Dynamize the field.** Continuous → pulsed → modulated → resonant/adaptive action.

**2.2.4 Structure the field.** Uniform → gradient, periodic, patterned, localized, standing/traveling-wave, multiplexed.

**2.2.5 Structure the substance.** Uniform → porous, layered, graded, perforated, composite, architected.

## 2.3 Transition to ferro-fields / magnetically controllable systems

**2.3.1 Add ferromagnetic material and magnetic field for remote/contactless control.**

**2.3.2 Disperse ferromagnetic particles in a non-magnetic carrier.**

**2.3.3 Use ferrofluid or magnetorheological/equivalent field-responsive media where justified.**

**2.3.4 Localize the field-responsive substance using capillary/porous/structured geometry.**

**2.3.5 Dynamize the magnetic field: pulsed, rotating, modulated, gradient, feedback controlled.**

## 2.4 Matching and mismatching rhythms

**2.4.1 Match action frequency to the natural/useful frequency of the target when resonance is beneficial.**

**2.4.2 Deliberately detune/mismatch to suppress harmful resonance/coupling.**

**2.4.3 Use two related periodic actions to create beats, envelopes, or controlled interference.**

## 2.5 Controlled transitions and field–substance interaction

**2.5.1 Move from an uncontrolled interaction to an externally controlled one.**

**2.5.2 Introduce feedback so the field changes with the state of the target.**

**2.5.3 Concentrate the field only where/when useful; reduce exposure elsewhere.**

**2.5.4 Use threshold/nonlinear responses to obtain self-regulation.**

**2.5.5 Couple multiple physical effects so one field prepares or amplifies another.**

**2.5.6 Use wave/standing-wave/localized field patterns to position energy or material transfer.**

**2.5.7 Evolve from rigid deterministic settings toward tunable/adaptive operating states.**

**2.5.8 Use the target's own response as part of the control/action loop.**

**2.5.9 Replace direct force transfer with a field-mediated interaction where it reduces wear, contamination, or inertia.**

**2.5.10 Introduce micro-/nano-scale field-sensitive structures when bulk response is too coarse.**

**2.5.11 Combine spatial structuring with temporal modulation for selective action.**

**2.5.12 Use preconditioning to place the system in a more responsive state before the main action.**

**2.5.13 Use post-action recovery/regeneration so the working medium/field resource is reused.**

# Class 3 — Transition to Supersystem & Micro-Level (6)

**3.1.1 Bi-system / poly-system.** Combine the system with one or more similar/identical systems.

**3.1.2 Develop links between elements of the bi/poly-system.** Coordinate them through a shared substance, field, control, or function.

**3.1.3 Increase differences among poly-system elements.** Identical → similar → diverse → complementary/opposite roles.

**3.2.1 Replace bulk substance with particles/granules/foams/gels/dispersions.**

**3.2.2 Use molecular/atomic/interface-level phenomena such as adsorption, catalysis, capillarity, surface tension, phase-boundary effects.**

**3.2.3 Use fields acting on microstructure: polarization, alignment, thermocapillary/Marangoni, electro-/magneto-rheology, etc.**

# Class 4 — Detection & Measurement (17)

## 4.1 Indirect measurement

**4.1.1 Modify the system so the hard-to-measure quantity becomes an easy-to-measure proxy/effect.**

**4.1.2 Avoid measurement entirely by designing self-regulation or invariant operation.**

## 4.2 Synthesis of measuring Su-Fields

**4.2.1 Build a measuring Su-Field: sensing substance + field + transduction.**

**4.2.2 Measure a copy/image/surrogate rather than the inaccessible original.**

**4.2.3 Add a marker/tracer/indicator substance.**

**4.2.4 Measure a field emitted/modified by the object rather than the object directly.**

## 4.3 Improving measuring systems

**4.3.1 Chain measurement/transduction stages.**

**4.3.2 Dynamize measurement: scan, sweep, modulate, lock-in, time-gate.**

**4.3.3 Measure derivative/integral/rate/accumulation instead of instantaneous quantity.**

## 4.4 Ferromagnetic / field-based measurement

**4.4.1 Use magnetic/electromagnetic phenomena for detection.**

**4.4.2 Magnetize or field-condition the object so another property becomes measurable.**

**4.4.3 Add field-responsive tracer/additive for indirect sensing.**

## 4.5 Evolution of measuring systems

**4.5.1 Move to bi/poly-sensor systems or multimodal sensor fusion.**

**4.5.2 Combine measurement with action so operation itself reports state.**

**4.5.3 Transition to micro-level measurement.**

**4.5.4 Make measurement self-correcting through feedback/cross-calibration.**

**4.5.5 Convert absolute measurement to comparative/differential measurement where it improves robustness.**

**4.5.6 Use redundancy/invariance to identify sensor failure or drift.**

**4.5.7 Infer hidden state from multiple observable effects using a validated model.**

# Class 5 — Strategies for Introducing Substances & Fields (17)

## 5.1 Introducing substances under restrictions

**5.1.1 Use 'nothing': voids, cavities, vacuum, bubbles, foams.**

**5.1.2 Use a field instead of adding a substance.**

**5.1.3 Use a temporary/external additive that does not permanently alter the system.**

**5.1.4 Apply the maximum dose/concentration only at the operational zone/time.**

**5.1.5 Use a substance that disappears after use: dissolve, evaporate, sublime, degrade, drain.**

## 5.2 Introducing fields under restrictions

**5.2.1 Use an existing internal field/waste field.**

**5.2.2 Use environmental fields/resources: gravity, ambient heat, solar, wind, background EM, pressure.**

**5.2.3 Use fields generated by adjacent supersystems.**

## 5.3 Phase transitions

**5.3.1 Use a phase transition for efficient interaction/control.**

**5.3.2 Use dual/multiphase states that satisfy changing requirements.**

**5.3.3 Use effects occurring during transition: latent heat, volume jump, conductivity/magnetism/solubility changes.**

## 5.4 Physical & chemical effects

**5.4.1 Use self-controlled threshold phenomena (Curie, glass transition, eutectic, boiling, ignition, saturation, etc.).**

**5.4.2 Amplify weak effects through feedback/cascade/avalanche where safe.**

**5.4.3 Use energy-conversion effects at interfaces/thresholds (piezoelectric, thermoelectric, photovoltaic, magnetostrictive, etc.).**

## 5.5 Generating useful substances

**5.5.1 Generate the useful substance from a system byproduct/resource.**

**5.5.2 Generate/use a counter-substance or opposite-reactivity agent to neutralize harm.**

**5.5.3 Generate particles/substances in situ by decomposition, electrolysis, ablation, sputtering, plasma, precipitation, or another validated process.**
