# Isolated public TNF/VHH reference audit

This research branch contains only public PDB references and artificial alignment tests. It does NOT contain private competition candidates, API keys, or model generation requests. It never changes main, places an order, creates accounts, uploads a competition submission, or optimizes known anti-TNF positives. The standard public GitHub runner executes CPU ANARCII numbering and MMseqs2 on public references only. The reference set is deliberately limited, not the competition's private patent database. Generated artifact records actual successes and failures; an arithmetic test is not called a real candidate search.

Public TNF complexes: 5M2I, 5M2J, 5M2M, 8Z8M. Non-TNF scope controls: 8Z8V (albumin), 7EOW (vWF). Public positive VHH sequences are for exclusion/reference only, never candidate submissions or affinity-optimization starting points.
