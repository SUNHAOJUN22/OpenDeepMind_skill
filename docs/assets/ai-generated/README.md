# Whole AI-generated scientific illustrations

All four current schematic assets are complete original PNG outputs of `image_gen.imagegen`. They contain no SVG/text overlays, composited labels or deterministic geometry. The images are conceptual, not quantitative scientific results. Exact editable equations and their domains are maintained in the main READMEs and scientific guides.
