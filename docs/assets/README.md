# README artwork and diagram archive / README 图像与图集

The active README artwork is localized independently. Chinese and English text and equations are stored as SVG outlines, so rendering does not depend on an installed CJK font. Each SVG embeds its original AI-generated PNG without changing the raster image. The precise text, source paths, hashes and synthetic-data labels are recorded in [artwork-provenance.json](readme-vnext/artwork-provenance.json).
